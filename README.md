### About

Miji builds software end to end, from user research and product definition to UI design, backend, database, and deployment. Most work starts with interviews and field research, then ships as a focused product with clear documentation, architecture decisions, and automated checks.

- Fintech and accounting systems with auditable, immutable records
- Operational tools for small businesses and public institutions
- Offline-first mobile apps for users with unreliable connectivity
- Data and research platforms with reproducible results

### Projects

| Project | Description | Stack |
|---|---|---|
| **FiniS** | Accounting and tax platform for Indonesian business groups: multi-company ledger, group consolidation, invoicing with approvals, inventory, VAT and withholding tax. | NestJS, React, PostgreSQL, Docker |
| **IDX Quant Lab** | Quantitative research platform for Indonesia Stock Exchange equities with IDX-rule-aware backtesting (lot, tick size, ARA/ARB, T+2), statistical validation, and daily paper trading. | Python, JavaScript, GitHub Actions |
| **Sistem Informasi Disposisi Surat** | Digital incoming mail and tiered disposition system for a provincial education office, with public status tracking by code or QR. | Next.js, NestJS, PostgreSQL, Redis, Docker |
| **SIMAWA UNIB** | Official student affairs portal for Universitas Bengkulu with scholarship, achievement, and organization data, live at [kemahasiswaan.unib.ac.id](https://kemahasiswaan.unib.ac.id). | WordPress, PHP, MySQL, REST API |
| **NADI POS** | Point-of-sale and bookkeeping app for food and beverage outlets, built from interviews with 11 businesses; keeps the cashier running offline. | Flutter, Dart, PostgreSQL, Docker |
| **Jejak+** | Export-ready traceability for smallholder coffee and cocoa producers: offline plot mapping, lot traceability, and EUDR geolocation data rooms. | TypeScript |
| **Lumbung+** | Local fresh-food marketplace connecting fishers, farmers, and livestock keepers directly with buyers, with seller, driver, and admin apps. | TypeScript |
| **InkSpace** | Social and commission platform for artists: feed, escrow-backed commissions, brief board, and digital asset store. | Flutter, Supabase |
